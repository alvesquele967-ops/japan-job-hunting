# 履歴書与職務経歴書
先扫描 `python <skill>/scripts/template_scan.py --directory <skill>/templates/resume`，再扫描用户上传/公司指定目录。支持 DOCX/XLSX/PDF，并报告旧 DOC/XLS 待转换，不盲目当可编辑 OOXML。扫描器读取内部文字与结构线索，PDF 可用 pypdf 时读取表单/文字，否则明确需要专业 PDF 工具。

优先级：公司强制格式 > 用户指定 > 通用模板；冲突说明并遵从公司要求。根据字段、文件名、页面大小、职位与用途推荐，不只依据扩展名。公司指定带个人内容模板只能放 workspace。空目录时说明没有可用模板，等待用户模板；不补充模式列为缺失继续其他工作，不擅自设计。仅用户明确要求无模板标准版时才制作。

Rikunabi 模板来源清单见 templates/resume/manifest.json，分类说明见 templates/resume/GUIDE.md。公开仓库不附带第三方模板文件，使用前按清单从来源网站下载；本地已有文件可直接使用。它们是通用/转职模板，不是已验证的新卒或 IT 专属模板。公司/学校要求优先。下载的填写示例不能当空白模板，也不能把示例中的人名履历写入用户画像。

使用当前可用 documents/spreadsheets/pdf 专业技能，应用前读取其规范；没有这些技能时用本地 python-docx/openpyxl/pypdf 与已安装办公软件、LibreOffice或可靠渲染器。缺少渲染/转换能力时说明局限，不能宣称视觉 QA 通过。依赖按需检查，不把特定机器绝对路径写入可移植流程。

复制模板到 workspace 后编辑，保留字体字号、表格、边框、合并、行列尺寸、页边距、分页、照片框和字段位置。DOCX 不粗暴重建段落破坏 runs；XLSX 写合并单元格锚点，保留打印区域/缩放；可填 PDF 优先填写 AcroForm，扁平 PDF 使用精确坐标覆盖并嵌入日文字体，不粗暴重排。照片仅使用用户提供/授权的真实照片，不生成身份照片。

字段映射：姓名、假名、生年月日、住址、电话、邮箱、照片、学历/职历及入离年月、资格、志望動機、自己PR、本人希望和模板其他字段。仅使用确认事实；假名或官方校名译名未知不猜，毕业未完成写已确认的卒業見込み。中日历法统一。无职历不把课程项目写成雇佣工作。
職務経歴書另按真实经历写职责、技术、行动和结果；新卒无正式工作时可用经用户确认的项目说明，标签准确。

检查事实与日期、公司职位名称、漏项和跨材料一致性；输出渲染后逐页查看溢出、裁切、字体缺失、分页、照片和线框。纸张以实际模板版面为准，文件名 A4/B5 不保证只有一页。
保留可编辑原格式，按要求另输出 PDF。例 `<company>_履歴書_<name>.docx/.xlsx/.pdf`；输出到 .jobhunt/documents/ 或公司 documents/，重名加版本。保存模板 hash、字段映射、claims.json、QA 记录和文件链接。不能转换 PDF 时交付可编辑文件并如实说明，不能把 Markdown 冒充提交文件。
