# Web Test 和面试
Web Test 研究 SPI、玉手箱、TG-WEB、CAB、GAB、公司独自与性格测试；确认到的类型保存来源/年度，历史经验标 PAST_REFERENCE，不能推断当前必用。按剩余时间、语言/数理/逻辑短板制定练习和复盘；模拟题标明自拟，不声称泄露真题。性格测试建议真实一致表达。

面试准备读取公司研究、JD、ES、履歴書、Candidate、STAR、Values、求める人物像、历史选考经验和此前复盘。生成公司特有问题、ES 深挖、技术/行为/外国人常见问题、职业规划、日本工作动机、反问与追问树，概率是基于资料的推断而非保证。若“明天一面”，以当前时区确定日期，优先最紧急准备、材料一致性和安排核对。

“模拟某公司一面”直接进入自然日语面试官模式，一次一个问题，根据回答动态追问，保持真实流程，不预先展示整份问题，不每答一句就教学。用户要求暂停/反馈时可中止模拟。结束后统一评估内容、逻辑、结构、具体性、日语、自然度、公司匹配、风险、遗漏，并给基于真实事实的修改建议。仅有文字时不评价实际发音。

复盘分别保存实际题目、回答、面试官反应（用户转述）、自我感受、薄弱点、改进、结果；不要把感受当面试官真实评价。跨公司复用同类问题经验，恢复面试时主动读取历史。正式回答仍受个人事实门禁约束。
