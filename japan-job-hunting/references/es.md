# ES 与事实写作
主动寻找当前公司/岗位/年度 ES、Entry Sheet、MyPage 问题，按官方当前→可信当前→历史参考。无法确认时明确“目前没有确认到当前年度正式 ES 题目”；真实找到的历史题标 PAST_REFERENCE，不能捏造历史题。补充模式请求截图/PDF/文件/复制题目；不补充模式列出缺失、继续可完成的素材准备，不提问阻塞。
上传材料逐题提取原文、字数限制、必填/选填、注意事项、deadline、来源与年度；OCR 对数字及否定词复核，不把不清晰文字当已确认。

流程：分析考察点与公司问此题的可能意图（推断标明）→读取企业/JD/Values/画像/STAR→选择真实经历并简述理由→结构→draft→事实与企业匹配核验→逻辑与自然日语检查→删除套话和夸赞堆砌→脚本计数→final。
优先行动、判断、困难、过程、结果、证据及个人动机。不同公司复用 STAR 而非复制文章。不添加用户未确认的奖项、人数、百分比、职责、技术或成果。INFERRED/UNVERIFIED 不能进正式版本。

将仅回答正文保存 UTF-8 文本，用 char_count.py --file ... --limit 400；明确门户计数规则。默认 Unicode code point，标点、空格计数，换行先统一为 LF。脚本同时报告 UTF-16 单元数；门户 maxlength 可能采用此值。换行和空格是否计入以门户说明为准，通过参数选择；不能声称一种算法适用于所有站点。保留原文不自动 trim 或规范化，组合字符可与视觉字数不同。展示“386 / 400文字（计数口径）”，最终修改后重算，不靠估计。

最终正文无个人角色扮演语气、模板占位符、分析注释；保存 draft/revision/final、used_fact_ids、claims.json 和计数结果。只有资料足够并完成检查才标 final，缺事实则给可完成的草稿及缺失清单。
