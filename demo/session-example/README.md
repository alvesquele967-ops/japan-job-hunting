# 轻量功能演示文件

这组文件来自一次手动测试会话，展示求职画像补充、公司初筛、企业记录、ES 草稿、履歴書草稿和事实校验等部分能力。演示条件不对应真实身份，文档均为草稿，未用于实际投递。

本次测试误用了 GPT-6，额度消耗较快，因此跳过了部分追问，只完成了轻量功能展示。这里的对话与文件不代表 Skill 的全部功能；完整能力还包括持续公司发现、详细企业研究、正式 ES 题目处理、Web Test／SPI、模拟面试、选考复盘、申请进度与 Offer 比较。
